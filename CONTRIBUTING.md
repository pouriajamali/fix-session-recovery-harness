# Contributing

Run the README demo/tests with a fresh directory. Report version/commit, OS,
exact command, expected/actual reason/exit and the smallest synthetic evidence.
Do not upload real FIX traffic, customer dictionaries, credentials, accounts,
private source or shared proprietary contracts/data. Preserve failed evidence.

Keep fixed News/admin loopback scope, parent-owned endpoint, strict nonce/phase
receipt, pre-parser caps, complete reports and verified clean-stop boundary.
Do not add broker settings, endpoint imports, real orders, arbitrary dictionaries,
plugins, executable overrides or generic engine features to this preview.
Meaningful behavioral changes need regression evidence; keep fault probes only
in the separate excluded test assembly. Never weaken checks to force a green demo.

Preserve MIT original attribution and the full separate QuickFIX Software License,
mandatory acknowledgment and naming/non-endorsement requirements. Do not rewrite
historical tags/signatures/assets or alter other projects/resume/profile files.
